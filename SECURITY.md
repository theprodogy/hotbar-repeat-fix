# Security Policy

## Supported versions

Only the latest release gets fixes.

| Mod version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting a vulnerability

Please don't report security problems in public issues.

Report them privately through GitHub: open the repository's [Security tab](https://github.com/theprodogy/hotbar-repeat-fix/security) and click **Report a vulnerability**. Include:

- the affected mod jar and Minecraft version
- what the problem is and what an attacker could do with it
- steps to reproduce

You'll get a reply within 7 days. Once the problem is confirmed, a fix ships in a new release, and you're credited in the release notes unless you'd rather not be.

## Scope

This is a client-only mod with no network code, file access or configuration. It only changes how hotbar key presses are counted. Problems in Minecraft, Fabric Loader or other mods should go to those projects.
