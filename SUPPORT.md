# Getting help

## Before asking

1. Check that the jar matches your Minecraft version. The table is in the [README](README.md#supported-versions).
2. Check your Java version. 1.21.11 needs Java 21 or newer, and 26.x needs Java 25.
3. Check that Fabric Loader 0.20.1 or newer is installed. Fabric API is not needed.
4. Look through [existing issues](https://github.com/theprodogy/hotbar-repeat-fix/issues?q=is%3Aissue), open or closed.

## Asking for help

- **Bugs or crashes:** open a [bug report](https://github.com/theprodogy/hotbar-repeat-fix/issues/new?template=bug_report.md).
- **Ideas:** open a [feature request](https://github.com/theprodogy/hotbar-repeat-fix/issues/new?template=feature_request.md).
- **Security problems:** see [SECURITY.md](SECURITY.md).

This is a hobby project maintained in free time, so replies can take a few days.
